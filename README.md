# 振镜激光打标仿真与工艺校验系统

面向 3C 电子与汽配产线打样场景的**纯浏览器端**激光打标仿真系统。所有计算与数据都在本地完成，
车间断网可运行，打样报告可导出为自包含 HTML 供客户验收与工艺评审。

## 技术栈

- **Vite + TypeScript + React 18 + Zustand**
- **WebGL2**：手写 2D 场图渲染器（能量热力/深度/打标成像）与 3D 线框预览（治具/工件/振镜幅面）
- **Web Worker**：逐脉冲能量累积在独立线程，不卡界面
- **IndexedDB（idb）**：工程、仿真结果、矩阵试打记录全部本地持久化
- **qrcode / jsbarcode / jsqr**：码图生成与真实解码评级，全部打包进 bundle，无运行时外网依赖

## 启动与离线部署

```bash
npm install
npm run dev      # 开发调试
npm run build    # 产出纯静态 dist/
npm run preview  # 本地预览构建产物
```

`dist/` 目录可整体拷到车间任意一台装了新版 Edge/Chrome 的电脑，双击或用任意静态服务器打开即可，
**不需要联网、不需要后端、不需要安装数据库**。工程数据可用「备份导出/恢复导入」做 JSON 迁移。

## 物理模型（工艺校验的核心）

系统**不使用平均功率凑数**，能量密度按实际打标点逐点累积：

1. **图档光栅化**：参数化对象渲染为二值掩膜；二维码按模块整数像素绘制后缩放，避免模块漂移。
2. **逐脉冲沉积**：振镜按脉冲间距 `v/f` 在掩膜格点上逐点发射脉冲，单脉冲能量 `E = P/f`，
   每个脉冲以 1/e² 高斯分布（截断 2σ）沉积到光斑覆盖的网格；多层、多遍全部累加到同一张 fluence 图。
3. **烧蚀深度**：超过材料气化阈值的净能量按体积去除率折算
   `深度(μm) = (F − F气化) × 烧蚀率(mm³/J) × 10`。
4. **离焦模型**：`w(z) = w0·√(1+(z/zR)²)`，瑞利长度由腰斑与波长计算；
   按图案最细线宽反推允许最大离焦量，超限提示重新对焦。
5. **码评级**：打标成像经二值化（模拟扫码器硬判决）后用 jsQR 真实解码，
   结合对比度、调制、模块变形给出 A–F 等级，扫不出的码直接标红。
6. **矩阵试打**：解析模型快速估算每个功率/速度/次数组合的峰值能量密度、深度与对比度，
   选中格子回填后再跑完整逐点仿真复核。

## 标定说明（重要）

内置材料库（304/铝/黄铜/碳钢/阳极铝/ABS/PC/PA）的烧蚀率、气化/热损伤/烧穿阈值为
公开手册与工程经验的**典型初值**，不同牌号、表面处理、激光器差异很大。
正式用于客户验收前，应在现场用首件实测深度对照仿真值，修正 `src/data/library.ts` 中
对应材料的 `ablationRate` 与三个阈值，再固化工艺。
